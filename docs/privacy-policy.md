# プライバシーポリシー

最終更新日: 2026-05-24

**SASO Willen Edition**（以下「本アプリ」といいます）は、SASO 倉庫在庫管理システムに接続するための Flutter 製モバイルターミナルアプリです。本アプリの開発・配布は Willen Federation コミュニティ（以下「当プロジェクト」といいます）が運営する非営利のオープンソースプロジェクトとして行われています。

本プライバシーポリシーは、本アプリがユーザーから収集・処理する個人データの種別、利用目的、第三者提供、保存期間、ユーザーが行使できる権利、および問い合わせ先について説明するものです。

---

## 1. 取り扱う個人データ

本アプリは、以下のカテゴリーの個人データを目的に応じて取り扱います。

| カテゴリー | 具体例 | 取得経路 |
|---|---|---|
| 認証情報 | ユーザー名、ハッシュ化されたセッショントークン、OIDC ID トークン | ログイン画面、Auth0 / Firebase Auth / SAML SSO |
| 端末識別子 | デバイス ID、FCM 登録トークン、AWS Pinpoint エンドポイント ID | OS 提供 API、Firebase / Amazon SNS |
| サーバー接続情報 | 接続先 SASO サーバーの URL、選択中の API モード | ユーザーが設定画面で入力 |
| バーコード・在庫データ | スキャンしたアイテム ID、フィーチャーコード、棚 ID、検索クエリ | ユーザーが本アプリを操作することで生成 |
| メディア | カメラ撮影画像、写真ライブラリから選択した画像（在庫写真用途） | カメラ API、写真ライブラリ |
| 端末情報・診断 | OS バージョン、アプリバージョン、機種名、エラーログ | 本アプリ内部 |
| オフラインキャッシュ | 上記のうち、ネットワーク断時に動作させるためのローカル SQLite キャッシュ | 本アプリ内部 |

本アプリは、Apple ID / Google アカウントの氏名・メールアドレス・電話番号などを単独で取得することはありません。

---

## 2. 利用目的

取得した個人データは、以下の目的の範囲内でのみ利用します。

- 接続先 SASO サーバーへのログインおよびセッション維持
- 倉庫在庫の検索・閲覧・更新を含む本アプリの中核機能の提供
- バーコードスキャン、棚ビュー、カテゴリブラウズ等の操作の補助
- プッシュ通知（在庫アラート、ペアリング通知、システム通知）の配信
- オフラインモードにおけるローカルキャッシュからのデータ表示
- 不具合の特定、利用状況の把握、セキュリティ対策のための診断情報の参照
- 法令上の義務の履行および当プロジェクトの権利・財産の保護

利用目的の達成に必要な範囲を超えて個人データを取り扱うことはありません。

---

## 3. 第三者提供および外部送信先

本アプリは、機能を提供するために以下の第三者サービスへ最小限のデータを送信します。これらのサービスは、それぞれの提供事業者のプライバシーポリシーに従って処理されます。

| 送信先 | 用途 | 送信されるデータ | 提供事業者のポリシー |
|---|---|---|---|
| 接続先 SASO サーバー（ユーザー指定） | 認証、在庫データの取得・更新 | 認証情報、検索クエリ、在庫更新内容 | 各サーバー運用者のポリシー |
| Google Firebase（FCM / Authentication / Remote Config） | プッシュ通知の配信、認証、フィーチャーフラグ取得 | FCM トークン、認証トークン、デバイスメタデータ | [Google プライバシーポリシー](https://policies.google.com/privacy) |
| Auth0 | OIDC / OAuth2 認証 | ユーザー名、ID トークン、リフレッシュトークン | [Okta（Auth0）プライバシーポリシー](https://www.okta.com/privacy-policy/) |
| Amazon Web Services — SNS Pinpoint | プッシュ通知配信（オプション） | エンドポイント ID、デバイスメタデータ | [AWS プライバシーポリシー](https://aws.amazon.com/privacy/) |

これらの送信は、ユーザーが該当機能（プッシュ通知、認証など）を有効化したとき、または接続先サーバーへログインしたときにのみ発生します。本アプリ自体が広告 SDK・アクセス解析 SDK を組み込むことはありません。

---

## 4. データの保存期間

- **接続先サーバーに送信されたデータ**: 接続先 SASO サーバーの運用者が定める保存期間に従います。
- **本アプリのローカルキャッシュ（SQLite / Secure Storage）**: ユーザーが本アプリをアンインストールするか、設定画面の「保留中データを送信」等で明示的に削除するまで端末内に保持されます。
- **認証セッショントークン**: ログアウトまたはサーバー側でセッションが失効するまで `flutter_secure_storage` 上に暗号化保存されます。
- **Firebase / Auth0 / AWS Pinpoint 上のデータ**: 各事業者のポリシーおよび当プロジェクトの設定（既定では FCM トークンはアプリ再インストール時に破棄）に従います。

---

## 5. ユーザーの権利

ユーザーは、本アプリおよび接続先サーバーで取り扱われている自身の個人データについて、以下の権利を行使することができます。

- 開示（保存されているデータの内容の確認）
- 訂正、追加、削除
- 利用停止または第三者提供の停止
- データの移行（可搬性）
- 同意の撤回

これらの権利の行使は、原則として接続先 SASO サーバーの運用者を通じて行ってください。本アプリ単体で削除可能なローカルキャッシュは、OS のアプリ削除またはアプリ内の該当機能から削除できます。

EU / EEA / 英国にお住まいの方は GDPR / UK GDPR、カリフォルニア州にお住まいの方は CCPA / CPRA に基づく権利を行使できます。

## 6. セキュリティ

本アプリは、個人データの漏えい・滅失・改ざんを防ぐために以下の対策を講じています。

- すべてのサーバー通信における HTTPS の強制（`authLegacyHttpsRequired` ガード）
- 認証トークンの `flutter_secure_storage`（iOS Keychain / Android Keystore）への暗号化保存
- セッション有効期限切れ時の自動ログアウト
- 証明書ピンニング（SHA-256）
- オープンソースとしての継続的なコードレビュー（[GitHub Issues](https://github.com/Willen-Federation/SASO-Willen-Edition-Flutter/issues) / [SECURITY.md](https://github.com/Willen-Federation/SASO-Willen-Edition-Flutter/blob/main/SECURITY.md)）
