# バーコードスキャン

`ff_barcode_scanner` フラグが ON（デフォルト）のとき、ホーム画面の FAB からバーコードスキャン画面を開けます。

---

## 対応フォーマット

| フォーマット | 用途 |
|------------|------|
| EAN-13 / EAN-8 | 商品バーコード |
| Code 128 | 物流・倉庫管理 |
| QR コード | URL・独自フォーマット |
| Code 39 | 産業用 |
| Data Matrix | 小型部品・電子基板 |

---

## 使い方

1. ホーム画面の **スキャン FAB**（:material-barcode-scan:）をタップ
2. カメラが起動し、スキャン枠が表示される
3. バーコードをスキャン枠に合わせる
4. 自動認識後、**8 桁の品番（YYMMNNNN）** であればアイテム詳細画面へ遷移

---

## カメラ権限

=== "iOS"

    `Info.plist` に `NSCameraUsageDescription` が設定済みです。  
    初回起動時に許可ダイアログが表示されます。

=== "Android"

    `AndroidManifest.xml` に `CAMERA` 権限が含まれています。  
    Android 6.0 以降では実行時権限として許可ダイアログが表示されます。

---

## トラブルシューティング

??? failure "カメラが表示されない（シミュレーター）"
    シミュレーターにはカメラがありません。実機で確認してください。

??? failure "スキャンしても反応しない"
    照明の明るい場所でバーコードとカメラの距離を 10〜30cm に調整してください。
