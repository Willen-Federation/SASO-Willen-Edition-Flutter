# オフラインモード

`ff_offline_mode` フラグが ON（デフォルト）のとき、SQLite キャッシュを使用してオフライン時もアイテム情報を参照できます。

---

## 動作概要

```
アイテム取得リクエスト
  ↓
キャッシュにヒット？ → キャッシュから返す（ネットワーク呼び出しなし）
  ↓ No
API から取得 → キャッシュに保存 → 返す
  ↓ ネットワークエラー
キャッシュにあれば古いデータを返す（オフラインフォールバック）
  ↓ キャッシュなし
エラーメッセージを表示
```

---

## キャッシュの仕様

| 項目 | 内容 |
|------|------|
| ストレージ | SQLite（sqflite） |
| キャッシュ対象 | アイテム詳細、カテゴリ一覧 |
| TTL | なし（手動クリアのみ） |
| 保存場所 | アプリのドキュメントディレクトリ |

---

## キャッシュのクリア

**「サーバー設定」** ページの **「キャッシュをクリア」** ボタンから全キャッシュを削除できます。

---

## モックモードとの関係

`ApiMode.mock` のとき、全データはインメモリモックから返されます。  
SQLite キャッシュは使用されますが、オフラインフォールバックは実質不要です（常にデータがある）。
