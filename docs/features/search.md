# アイテム検索

ホーム画面の検索 FAB からアイテムを名前・品番で検索できます。

---

## 使い方

1. ホーム画面の **検索 FAB**（:material-magnify:）をタップ
2. 検索フィールドに品名またはアイテム ID を入力
3. **検索アイコン** をタップするか、キーボードの「完了」を押す

### ダイレクトナビゲーション

**8 桁の品番**（例: `26040001`）を入力して検索すると、検索結果画面をスキップして直接アイテム詳細画面へ遷移します。

---

## アイテム ID 形式

アイテム ID は `YYMMNNNN` の 8 桁数字です：

| 部分 | 意味 | 例 |
|------|------|-----|
| `YY` | 登録年（下 2 桁） | `26` = 2026年 |
| `MM` | 登録月 | `04` = 4月 |
| `NNNN` | 連番 | `0001` = 1番 |

---

## 検索対象

- アイテム名（日本語・英語）
- アイテム ID（完全一致 or 前方一致）
- カテゴリ名

---

## バーコードスキャンとの連携

バーコードスキャン画面でスキャンした 8 桁品番は自動的にこの検索フローを経由してアイテム詳細へ遷移します。
