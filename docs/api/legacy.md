# レガシー API 接続

既存の SASO PHP バックエンドに接続するためのガイドです。

---

## 前提条件

- SASO サーバーへのネットワークアクセス（同一 LAN または VPN）
- SASO ログイン権限を持つアカウント

---

## 接続設定

1. アプリを起動し、設定アイコンをタップ → **「サーバー設定」**
2. **「サーバー URL」** に SASO サーバーの URL を入力（例: `https://saso.example.com`）
3. **「API モード」** で **「Legacy」** を選択
4. **「保存」** をタップ

---

## 認証

接続後、ログイン画面が表示されます：

- **ユーザー名**: SASO アカウントのユーザー名
- **パスワード**: SASO アカウントのパスワード

認証成功後、セッション Cookie が Secure Storage（iOS Keychain / Android Keystore）に保存されます。

---

## 対応エンドポイント

| エンドポイント | 用途 |
|--------------|------|
| `POST /item/start` | アイテム検索 |
| `GET /category/list.json` | カテゴリ一覧 |
| `GET /item/detail/:id` | アイテム詳細 |

---

## REST API v1（将来対応）

`ff_rest_api_v1` フラグを ON にすると、REST API v1（`/api/v1/*`）を使用します。  
現時点ではスタブ実装です。SASO バックエンドの M3 リリース後に完全実装予定です。

---

## トラブルシューティング

??? failure "接続できない"
    - サーバー URL が正しいか確認（`https://` を含む完全な URL）
    - 同一ネットワーク上にあるか確認（VPN 接続が必要な場合も）
    - HTTP のみの環境では `http://` を使用（本番環境では HTTPS を推奨）

??? failure "ログインできない"
    - ユーザー名・パスワードを再確認
    - SASO サーバー側でアカウントが有効か確認
