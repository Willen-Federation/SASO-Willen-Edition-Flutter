# モックモード（サーバー不要）

モックモードでは、実際の SASO サーバーに接続せずアプリを動作させられます。  
開発・デモ・テスト用途に最適です。

---

## 有効化

アプリ起動時はデフォルトでモックモードが選択されます。  
バナーに **「モックモード（サーバー不要）」** と表示されていれば有効です。

**サーバー設定** ページから変更可能：

1. 設定アイコンをタップ → **「サーバー設定」**
2. **「API モード」** で **「Mock」** を選択
3. 保存

## テストでの使用

インテグレーションテストはモックモードで実行されます：

```bash
make test-integration
```

`pumpAppInMockMode()` ヘルパーが `serverConfigNotifierProvider` をオーバーライドし、  
サーバー接続なしでテストを実行します。
