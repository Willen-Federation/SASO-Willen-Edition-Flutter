# プライバシーポリシー

最終更新日: 2026-05-24
発効日: 2026-05-24

Willen Federation（以下「当組織」）は、モバイルアプリケーション **SASO Willen Edition**（Android 版 / iOS 版、以下「本アプリ」）を提供するにあたり、利用者の個人情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

本ポリシーは Google Play および Apple App Store の双方の要件を満たすことを目的とし、Android 版（Issue #142）および iOS 版（Issue #122）で共通の本文を採用します。

## 2. 本アプリの位置付け

本アプリは **SASO 倉庫在庫管理サーバー** に接続し、現場作業者がスマートフォンから在庫照会・バーコードスキャン・棚管理を行うためのクライアント端末です。

- 個人情報を含む業務データの**保管・利用責任は接続先の SASO サーバーを運用するテナント企業**にあります。
- 本アプリ自体は端末上に必要最小限のキャッシュおよび認証情報を保存します。
- 本ポリシーは「本アプリが端末上で取り扱う情報」を対象とし、各テナント企業が SASO サーバー上で保管・利用するデータの取扱いは別途、各テナント企業のプライバシーポリシーに従います。

## 3. 収集する情報

本アプリは以下の情報を収集・利用します。

### 3.1 認証情報

| 種別 | 内容 | 保存場所 |
|---|---|---|
| ユーザー名 / パスワード | サーバーへの認証時のみ送信。**端末には保存しません**。 | （保存なし） |
| JWT アクセストークン / リフレッシュトークン | REST モードでの API 認証に使用 | 端末のセキュアストレージ（Keychain / Keystore） |
| セッションクッキー | レガシーモードでの API 認証に使用 | 端末のセキュアストレージ（暗号化） |
| ペアリングトークン | QR ペアリング時に発行される短期トークン | メモリ内のみ（永続化なし） |

### 3.2 SAML / SSO 属性

SSO（SAML / OIDC）でログインした場合、認証プロバイダから次の属性を受領します。

- 氏名
- メールアドレス
- 部署 / 役割（IdP の設定に依存）
- グループメンバーシップ（IdP の設定に依存）

これらの属性は**サーバーが保持するセッションに紐づき**、本アプリ端末上にはセッション識別子のみが保存されます。

### 3.3 端末 / プッシュ通知関連

| 種別 | 用途 |
|---|---|
| FCM 登録トークン（Android） | プッシュ通知の宛先識別 |
| APNs デバイストークン（iOS） | プッシュ通知の宛先識別 |
| Amazon SNS エンドポイント ARN | 補助的なプッシュ配信識別 |
| デバイス ID（アプリインストール時に生成する UUID） | ペアリング済み端末の識別 |
| OS バージョン / アプリバージョン | 互換性確認、エラー解析 |

### 3.4 利用ログ / 診断情報

| 種別 | 用途 |
|---|---|
| エラーログ（クラッシュ・例外スタックトレース） | 障害解析および品質向上 |
| API リクエストのタイムスタンプ / ステータスコード | 接続診断および監査 |
| バーコードスキャン履歴（端末ローカル） | UX 向上およびオフラインキュー処理 |

エラーログには認証クレデンシャル本体（パスワード・JWT 本体）を含めない設計としています。

### 3.5 カメラおよび写真 / メディア

| 利用シーン | 取得対象 | 端末外への送信 |
|---|---|---|
| バーコードスキャン | カメラ映像 | **送信なし**（端末内デコードのみ） |
| 商品画像 / 棚画像のアップロード（任意機能） | 写真ライブラリの選択画像 | ユーザーが明示的に送信した画像のみ SASO サーバーへ送信 |

カメラ映像そのものを録画・保存することはありません。

## 4. 情報の利用目的

収集した情報は以下の目的のみに利用します。

1. SASO サーバーに対するユーザー認証およびセッション管理
2. 業務データ（在庫・カテゴリ・棚情報）の表示・更新
3. オフライン時の操作キューイングおよび復旧後の再同期
4. プッシュ通知の配信
5. 障害解析・セキュリティ監査・品質向上
6. 法令またはガイドラインへの対応（Google Play / App Store ポリシー、個人情報保護法、GDPR 等）

利用目的を超えて広告配信・行動分析・第三者への販売を行うことは**ありません**。

## 5. 第三者提供 / サブプロセッサ

本アプリは以下の第三者サービスと通信します。各サービスのプライバシーポリシーは各社の規約に従います。

| サービス | 提供者 | 目的 | 共有される情報 |
|---|---|---|---|
| Firebase Cloud Messaging（FCM） | Google LLC | Android プッシュ通知配信 | FCM 登録トークン、通知ペイロードの一部 |
| Apple Push Notification service（APNs） | Apple Inc. | iOS プッシュ通知配信 | APNs デバイストークン、通知ペイロードの一部 |
| Amazon SNS / Pinpoint | Amazon Web Services, Inc. | プッシュ配信補助、エンドポイント管理 | デバイストークン、エンドポイント ARN |
| Auth0 | Okta, Inc. | OIDC / SSO 認証（テナントが Auth0 を利用する場合のみ） | ユーザー識別子、認証属性 |
| Netlify | Netlify, Inc. | 本プライバシーポリシーの公開ホスティング | 閲覧時の IP アドレス（標準アクセスログ） |
| Sentry（任意） | Functional Software, Inc. | クラッシュレポート（テナントが有効化した場合のみ） | スタックトレース、アプリバージョン、OS バージョン |

業務データ本体（在庫情報、SAML 属性、業務イベント）は、**各テナント企業が運用する SASO サーバー以外には送信されません**。

## 6. データの保存期間

| データ | 保存期間 |
|---|---|
| JWT アクセストークン | 期限切れ（最長 1 時間）またはログアウトまで |
| JWT リフレッシュトークン | 期限切れ（最長 30 日）またはログアウトまで |
| セッションクッキー | サーバー側セッション失効まで |
| FCM / APNs トークン | アンインストール時または OS による無効化まで |
| オフラインキュー | サーバー送信完了またはユーザーによる手動削除まで |
| ローカルキャッシュ（在庫・カテゴリ） | アプリのキャッシュクリアまたはアンインストールまで |
| 認証情報全般 | ログアウト時に全件削除 |

## 7. 利用者の権利

利用者は以下の権利を有します。GDPR 適用地域の利用者は同等の権利を有します。

1. **開示請求**: 本アプリが端末上で保持する情報の開示
2. **訂正請求**: 誤った情報の訂正
3. **削除請求**: ログアウトおよびアプリのアンインストールにより端末上のすべての個人情報を削除可能
4. **利用停止 / 撤回**: プッシュ通知の OS 設定によるオプトアウト、カメラ / 写真権限の取消
5. **データポータビリティ**: SASO サーバー側のデータについては各テナント企業に請求

請求は GitHub Issues またはテナント管理者経由でお願いします。

## 8. 子ども（児童）について

本アプリは業務利用を目的としており、**13 歳未満の児童による利用を想定していません**。児童から意図せず情報を収集した場合は、確認次第削除します。

## 9. セキュリティ

- 認証情報は OS 提供のセキュアストレージ（Android Keystore / iOS Keychain）に保存します。
- サーバーとの通信はすべて HTTPS（TLS 1.2 以上）を要求します。
- ローカル DB（SQLite / 暗号化済み）でオフラインキューを管理します。
- 既知の脆弱性については [SECURITY.md](https://github.com/willen-federation/saso-willen-edition-flutter/blob/main/SECURITY.md) の手順でご報告ください。

## 10. 本ポリシーの変更

法令の改正、提供機能の変更、第三者サービスの追加などにより、本ポリシーは予告なく変更されることがあります。重要な変更がある場合は、アプリ内通知、本ページの「最終更新日」更新、および GitHub リリースノートでお知らせします。
